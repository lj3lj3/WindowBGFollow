WindowBGFollow · 窗口背后跟随背景图

原生 Swift 实现的 macOS 工具：让一张背景图实时贴在当前焦点窗口背后，随切换、拖动、缩放同步，为窗口提供可透出的背景层。

macOS 12+ · Tahoe 验证 单文件 Swift · ~380 行 CPU 基线 ~0.7% 辅助功能授权 ×1

一、核心特性

精确 z-order 垫底

order(.below, relativeTo:) 真配对——目标窗口被盖时背景跟着被盖，非桌面壁纸式近似。

实时跟随

AX 事件 + 拖拽期 60Hz 补帧双通道，切换/拖动/缩放逐帧同步。

每屏常驻副本

每个显示器一个独立 overlay，永不跨屏移动，切换显示器零闪现。

快速关闭响应

AX 销毁通知 + 250ms 焦点巡检兜底，残留 ≤250ms。

低资源

静止 CPU ~0.7%，图片 720p 基线降采样解码。

可配置

背景图与 app 白/黑名单均为独立文件，配置热生效。

二、运行原理

激活通知 / 250ms 巡检→ CGWindowList 定位焦点窗口→ order(.below) 垫到窗口后→ AXObserver + 拖拽 60Hz 补帧
模块机制
目标定位CGWindowList 过滤 layer 0 + 前台 app PID，无需权限
垫底排序NSWindow.order(.below, relativeTo: 窗口号)，窗口号全局有效、跨进程
移动跟随AXObserver 订阅 moved/resized；拖拽期 leftMouseDragged 触发 60Hz 补帧
关闭检测AXUIElementDestroyed 通知 + 250ms 焦点窗口号比对巡检
跨屏防闪按屏维护 overlay 副本，切屏=换副本，无跨屏位移
权限仅要求辅助功能（Accessibility）；读取窗口 frame 不需要屏幕录制权限。

三、构建与运行

git clone <repo-url> && cd WindowBGFollow
./build.sh
open WindowBGFollow.app

首次运行后在 系统设置 → 隐私与安全性 → 辅助功能 勾选 WindowBGFollow。

四、配置

背景图

WindowBGFollow/
├── WindowBGFollow.app
├── bg.jpg        ← 背景图（bg.jpg / bg.jpeg / bg.png，替换后重启 app）
└── config.json   ← app 过滤配置（可选，热生效）

启动时按 720p 基线（最长边 1280px）降采样解码；渲染为 aspect-fill 裁剪 + 26px 圆角（对齐 macOS 26）。

app 过滤（config.json）

{
  "whitelist": [],
  "blacklist": ["com.tencent.wechat"]
}
字段语义
whitelist非空时仅列表内 app 生效
blacklist白名单为空时跳过列表内 app
留空两列表均空 = 对所有 app 生效

值为 bundle id，查询：osascript -e 'id of app "应用名"'；修改后 ~250ms 热生效。

五、已知边界（系统级硬限制）

场景表现原因
不透明窗口（Chrome/Finder）整图被盖住，仅圆角缺口透出窗口不透明是 app 自身属性，外部无法穿透采样
关闭残留极端情况 ≤250ms部分 app 不发 AXUIElementDestroyed，靠巡检兜底
拖动流畅度落后合成 1~2 帧WindowServer 合成帧率是追踪类工具的物理极限

六、实现备忘（给维护者）

坑处置
AXUIElementGetWindow 未暴露给 Swiftdlsym 从 ApplicationServices / HIServices 动态加载，缺失时降级
macOS 26 SDK 签名变化AXUIElementCopyAttributeValue 已是 3 参数（无 error 指针）
AXObserver 静默失效必须强持有 + 手动挂 RunLoop source，retarget 时移除旧 source
切换全屏闪图showOverlay 只用 order(.below)，禁止 orderFront
